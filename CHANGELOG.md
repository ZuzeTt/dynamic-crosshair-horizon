# Changelog

## 9.15.0 — first Horizon release

- Native Horizon port of Crendgrim's Dynamic Crosshair 9.15.0 (Minecraft 26.3, Horizon
  `0b14f8a`).
- Full interaction pipeline: primary/secondary interactions, style coalescing, tool
  markers and the Always / If Targeting / If Interactable / Disabled policies.
- Item, block and entity rules from the original mixins, including containers,
  doors, signs, cakes, cauldrons, bookshelves, horse/boat/animal interactions,
  shears, buckets, brushes and spawn eggs.
- All builtin crosshair styles plus configurable colours and blending; custom PNG
  styles from `config/dynamiccrosshair/crosshairs/`.
- Settings on **Options > Mods > Dynamic Crosshair**, the original datapack tags,
  third-person crosshair, hide-with-screen/map and the centered-crosshair option.
- GitHub-installable package: `dynamiccrosshair-9.15.0.hmod`.
